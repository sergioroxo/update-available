# GOV.UK Glossary Lexicon Connections To Validate

Source: https://www.gov.uk/government/publications/conversion-therapy-an-evidence-assessment-and-qualitative-study/appendix-1-glossary

This checklist records the connection work created by importing the GOV.UK conversion-therapy glossary into the local seed lexicon. The terms are useful baseline vocabulary, but relationships still need researcher validation before public-facing graph or Wikia use.

## High-Priority Equivalence / Variant Checks

- Conversion Therapy -> SOGICE -> Conversion Practices -> SOCE -> GICE.
- Reparative Therapy -> Conversion Therapy -> SOCE -> Reparative Therapy Logic.
- Sexual Orientation Change Efforts -> SOCE -> Conversion Therapy.
- Gender Identity Change Efforts -> GICE -> Conversion Therapy -> SOGICE.
- Unwanted Same-Sex Attraction -> USSA -> Same-Sex Attraction -> SSA.
- Ex-gay -> Ex-gay Movement -> Ex-gay Ministry -> Changed -> Change Story.

## Identity / Reference Term Boundaries

- LGBTQ+ should connect to Lesbian, Gay, Bisexual, Transgender, Queer, Intersex, Asexual, and Aromantic as an umbrella term.
- Homosexual should connect to Gay and Lesbian, but review context carefully: it can be clinical, historical, self-descriptive, stigmatizing, or hostile.
- Queer should not be treated as hostile by default; review whether the term is reclaimed, academic, political, or used pejoratively.
- Cisgender, Heterosexual, Gender Identity, Gender Reassignment, Gender Incongruence, Gender Variance, and Transgender are reference terms unless a source weaponizes them.

## Anti-Trans / Policy Interpretation Checks

- Detransition is a reference term, but may connect to Anti-Trans/ROGD rhetoric when used as proof against transition or affirmation.
- Gender Incongruence should be reviewed against Gender Dysphoria and clinical-document context before merging or using as a variant.
- Gender Reassignment is a UK legal/equality-law term and should not be auto-merged into general Transgender without preserving legal context.

## Evidence Graph Safety

- Do not publish these relationships as graph facts until a relation has corpus evidence or researcher approval.
- Use GOV.UK glossary provenance as source support for term existence, not as proof that a term is a SOGICE tactic.
- For public graph exports, keep neutral identity/reference terms visually distinct from tactics, practices, organizations, and quote-backed claims.
