**The program died; the watching dispersed** is a fair, sourced summary of that. D31 was never

## Three things GPAHE adds that make the beat BETTER

**1. It wasn't only dispersal — it was RENAMING, and that is the piece's own grammar.**
NARTH became **ATCSI in 2014**. The organisation didn't die; it shipped a new name. GPAHE's 2023
report finds the same at the language level: providers adopt **medical-sounding terms**
("reintegrative therapy," "SAFE-T") specifically to evade content moderation.
→ **Refinement worth making:** the strongest version of the dispersal may not be *"could not be
removed"* but *"could not be removed — renamed."* An uninstaller that reports success while the
process continues under a new label is both more documented and more frightening, and it is exactly
what the piece already argues about updates. *(The u4 changelog's "change"→"calling" softening, D5,
is the same mechanism — this would rhyme.)*

**2. "Exodus shut down" is only half true, and the other half is darker.**
GPAHE lists **Exodus Global Alliance** as currently operating **200+ affiliated ministries
worldwide**. Exodus *International* (US) closed in 2013; a differently-named sibling never stopped.
→ The piece's u3 copy currently says the network "is no longer able to vouch for itself" and that
your file has been "migrated to a brighter place." That is accurate — and the fact that a parallel
body simply carried on gives the migration line a real referent. **⚑ Care needed:** this is a real,
named, currently-operating organisation. Under CLAUDE.md it may appear in **dossier/provenance only**,
never in the fiction. The scene keeps invented marks (Restorify → GracePlatform).

**3. It is not a despair story, and the piece shouldn't tell it as one.**
The 2023 report finds deplatforming **partially worked**: Facebook and Instagram eliminated the
recommendation rabbit holes, Bing improved markedly, TikTok performs best and shows warnings.
YouTube remains "a disaster." Non-English content is least moderated.
→ The dispersal is real, but it is *contested ground*, not an unstoppable force. That matters for
the piece's own laws: the respite is never a trap, and the Close is solidarity rather than defeat.
**Stage the dispersal as what it is — a system that survived by scattering — not as omnipotence.**
