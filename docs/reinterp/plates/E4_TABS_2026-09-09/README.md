# ERA 4'S BROWSER — the six tabs, and the order

*Rendered 2026-09-09. Kept in the repo rather than a scratch directory because
the last set was lost to a reboot.*

## The order is the argument
Sérgio, 2026-09-09: *"You should decide the order, maybe that will influence the
cadency of what people will actually see and the main one to be first."*
Decided, and it walks the apparatus's own ladder left to right:

| | | |
|---|---|---|
| `search` | **SEE** | it watched what she typed and finished the sentence first |
| `chat` | **CLASSIFY** | it names her, and files the naming |
| `record` | **PRESERVE** | the file outranks her, and cannot be edited from inside it |
| `photos` | **IMPROVE** | it makes a better version of her, and keeps that one |
| `care` | **INTERVENE** | it acts on her life, in four defensible steps |
| `extra` | — | the tab she did not open |

⚑ **`search` is first because it is the one that works as a still image.** It is
the tab that is live when the session restores, so it is the only page every
player is guaranteed to meet, and it states the era in four lines with no
interaction. It is also the only tab deliberately not pressable — which is why
it cannot be anywhere else: as a page you *go to* it reads as a dead end, as the
page you *arrive on* it reads as evidence.

⚑ **The chat is second on purpose, not demoted.** It is the strongest surface in
the era, and the ladder only means anything in order — a player who opens one
more tab gets it.

## The restore
`00_restoring` · `01_five_back` · `02_the_sixth_lands`.

Five tabs come back at an even beat, because they are one set: the session she
left. Then a pause three beats long, and a sixth lands on its own — and the row
**reflows to make room for it**, which is the strip rearranging itself for
something that was not part of the session. Nothing marks it and no line ever
mentions it again.
