# 8 · THINGS THAT COST TIME THIS WEEK, so they are not repeated
- ⚑ **Editing source while a walk runs kills it.** Did it twice.
- ⚑ **A string replace on a non-unique string.** `euler: { x: 82, y: 90, z: 0 }` is Room 2's
  workstation AND Room 3's monitor; replacing "the first one" flipped the wrong screen and I then
  debugged a bug I had just made. **Edit by line for shared values.**
- ⚑ **Prop `size` is `[x, y, z]` and the yaw rotates the mesh, not the array.** A "thin panel" written
  `[0.54, 0.41, 0.02]` is a half-metre slab along x, and the screen plane ended up inside it.
- ⚑ **A model manifest `scale` is a multiplier on a fitted model, not metres per native unit**, and
  `baseY` is in native units.
- ⚑ **Draw a magenta field through the pipeline before reasoning about it.** Ten rounds of texture
  theory were settled in one render.
- ⚑ **Look at the image; do not count its pixels.** I "verified" a plane by counting magenta and
  missed that it filled the screen.
- ⚑ **A sweep that does not look down far enough invents findings.** −20° reported five phantom
  blocked props; −60° found none.
