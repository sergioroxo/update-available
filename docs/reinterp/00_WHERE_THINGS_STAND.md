## The standing traps, learned the hard way
1. **A comment is not evidence.** Six sessions repeated a false claim from a stale header; a decision
   was once applied to a config constant nothing read.
2. **Content that exists cannot always be met.** Checks prove files exist, never that a player can
   reach them. C9 now fails the build on unreferenced content.
3. **"The geometry is correct" is not an answer to "I can't see it."** Four sessions measured a duck
   that did not exist — it was a yellow box.
4. **Old behaviour on device is the Safari cache, not a failed deploy.** Test in a Private tab.
5. **Read test output whole.** It reports on one long line; truncating it turns red into green.
6. **Never raise a ratchet baseline to make a run pass.**
