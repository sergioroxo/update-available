## 1 · 1997: how he gets to the channel — the system tells him, the web shows him the rest
The problem he names: before S190 the system opened the channel for him; now it opens a search, and a visitor may
not see why the channel matters. The answer is to make both true at once:
- **The dial-up lands on the fellowship's PORTAL** — the browser's home page, set by the companion disk (the kit
  "filled in the details", its own wizard says). The portal says what the kit said: *#stillstruggling — tonight,
  others like you — a mentor will find you there*, with one big **Join the channel** button. Under it: the Seekr
  search box (his query already in it), and **Resources**. The system instructs; the web is there to explore.
- **The channel and the browser are two windows, each with its taskbar button**, so he can go back and forth. Joining
  the channel does not close the browser; it minimises it. The browser stays on the desktop (an icon) for the rest
  of 1997.
- **The helper line** (the taskbar's side-message, Era 1's system voice): while the browser is open and nothing has
  happened for a while, a soft line — *"browse the fellowship's pages, or go to the channel. someone is waiting
  there."* — and once the channel is joined and Rob is quiet, the other way round — *"while you wait: the fellowship's
  pages are still open."* Soft lines step aside for any real line (the guide's existing law).

## 3 · The helpers keep people doing (Phase 6, folded in)
The narrative helper of each era — **1997 the system's side-messages · 2003 Lamby · 2016 Lambient · 2026 L** — gets
three kinds of line, all in the taskbar lane each already has:
1. **"While you wait"** — at every known wait (the dial-up, the channel before Rob, an install, the session's waits),
   a soft line naming something to do: browse the pages, the handheld, the forum, FloppySheep, Tag the video. Never a
   timer, never a score; it steps aside for any real line.
2. **The way back** — after a stretch of exploring with no progress, one line pointing to the main thread (the
   channel, the check-in, the board, the program). Exploration is always allowed; the way back is always named.
3. **The guided first filing** — the first time something is filed in 1997: *"something was filed. it is behind
   you."* Once, never again. And at each update's install, one line on whose file carries over: *"Daniel's file:
   carried over, scanned"* (1997→2003) · *"Daniel's file: archived. A new file is opened: Vera."* (2003→2016) ·
   *"Vera's file: archived. A new file is opened: Maya."* (2016→2026).
