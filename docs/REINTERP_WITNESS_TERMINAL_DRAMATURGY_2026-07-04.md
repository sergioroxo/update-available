## W1. What the terminal is

The O3 re-captioning screen made **persistent and cumulative**. At profile creation the player watched
their warm self-descriptions return as system categories ("I keep a diary" → "self-monitoring:
enabled"); the terminal is that same translation running for the whole piece — a wall-mounted case
file that only ever contains *what you actually did*, in the apparatus's language.

**Voice (◆W1):** system case-file third person, using the pre-filled name — "DANIEL: …" — never "you."
Rationale: the horror of the record is that it is *about* you without being *to* you; second person
would make the terminal a narrator, and the frame never plays. (Alternative if Sérgio wants it
crueler-warmer: the guide's chipper first-person-plural, "we noticed…" — I recommend against; that
voice belongs to the guide, and the terminal must feel authorless.)

## W2. Line grammar — the trace token is the law made visible

Every line = **caption + trace**, one line, era-styled:

```
DANIEL — self-monitoring: enabled          · source: your selection, "I keep a diary"
DANIEL — support declined ×2               · source: your click, [×] on Lamby
DANIEL — session: completed · outcome: none · source: your click, "Finish"
CROSS-REF — file 2 (women's track)          · source: your visit, west room
VERA — polish refused (1 line)              · source: your click, "Keep as written"
```

- **The trace token is mandatory.** No line exists without `· source: your <act>`. This is Ethics #10
  as a *visible grammar*, auditable by the player at any moment: if a line ever appeared that they
  couldn't trace, the piece would be lying — so the build rule is mechanical: **terminal lines are
  generated ONLY from ledger writes, and every ledger write carries its act** (see W5).
- **No timestamps** (no real clocks in the piece) — lines carry the era stamp only ('97 / '03 / '16 /
  now), which is how the record shows *time passing over the same person*.
- Declines, dismissals, refusals file with identical typography to compliances. The record does not
  editorialize; the re-captioning IS the editorial.

## W3. When it is readable — "it never writes while watched"

- **Always physically present** from the first filing (e1.b03 lights line 1; before that the terminal
  is dark glass — the old dead-system prop is gone, S9).
- **Readable whenever gazed at** (the turn is the only ask; flat mode keeps the flip surface as
  shipped).
- **The one behavior law: the terminal NEVER writes on-screen.** Lines are appended only while the
  player is facing away; you turn around and it is already longer. The player never once catches it
  in the act. (◆W2 — this is the creep mechanic; it needs Sérgio's yes. It is cheap: buffer ledger
  lines while `facingBack`, flush on facing-away. The cold-creep vignette already nudges the turn.)
- **Reading is never punished and never rewarded** — no mechanic keys off looking at the terminal
  except the shipped dossier-unlock-on-return, which stands.

## W4. Growth across eras (the terminal is the piece's memory organ)

- **It never resets.** T2's EULA scrolls the E1+E2 lines as "transferable assets" (choreography §T2);
  E3 opens with `DANIEL — case resolved — transferred` already on the wall; s3's carry-back REOPENS
  his file as "referenced material." The terminal is where dead eras stay alive.
- **Era re-skins, content accumulates:** '97 dot-matrix face → '03 grey client window → '16 pastel
  card list → present dark-mode feed. Same lines, restyled — the record outliving every interface
  that displayed it (rebrand-not-death told by typography).
- **Cross-references are its dramaturgical currency:** every send (master script §4) writes a
  `CROSS-REF` line linking two files. By E4 the terminal reads as a mesh of references — the visual
  seed of the Close (the constellation is this mesh, inverted warm; the terminal hands its lines to
  the sky at x.b1).

## W6. What the terminal never shows

- **Dossier/documentary text** — sources live on the dossier surface with `status:` tags (law).
  The terminal cites only the player. The two surfaces must never blur: the dossier is *our* evidence
  about the world; the terminal is *its* evidence about you.
- **Other subjects' full files.** Sends yield cross-reference STUBS ("file 2 — women's track"), never
  another person's readable record — the other victims are files you can't open, which is both the
  ethics (no invented survivor interiority on a system surface) and the dread.
- **Anything the player didn't do.** No inferred feelings, no predictions. The apparatus's
  *interpretations* are exactly as far as it goes ("self-monitoring: enabled" is an interpretation of
  a real click — that gap is the whole piece).

## W7. The Close inversion (handoff, already choreographed)

At x.b1 the terminal's lines lift into the constellation's first warm nodes (choreography §T4). The
record the system kept becomes the community's data — the same facts, re-owned. The terminal goes
dark AFTER the lamp, before the chord. It is the only system surface that gets a dignified death,
because it was the only one that never lied.
